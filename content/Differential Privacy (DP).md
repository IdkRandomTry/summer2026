> [!idea]
> The motive behind DP is to reduce the influence of one record in data upon the output of a function of entire data in order to protect the privacy of that record. This is often achieved by adding noise. 
> Another way to put it is: If an adversary looks at the final output and sees a value, it is statistically impossible for them to tell whether that value was generated by the dataset _with_ you or _without_ you.

 Suppose there are 2 datasets $D_1$ and $D_2$ which differ by exactly 1 record. Suppose a randomized algorithm $A$. $A$ satisfies $\epsilon$-differential privacy, iff for any set of outputs $S \subseteq Range(A)$:
 
 $$Pr[A(D_1) \in S] \leq e^\epsilon~~ \times Pr[A(D_2) \in S ]$$

In above Definition $D_1$ and $D_2$ are called *neighbouring datasets*

Alternate Definition:
*A mechanism is* $\epsilon$*-indistinguishable if for all pairs* $\mathbf{x}, \mathbf{x}' \in D^n$ *which differ in only one entry, for all adversaries* $\mathcal{A}$*, and for all transcripts* $t$:

$$\left| \ln\left( \frac{\Pr[\mathcal{T}_{\mathcal{A}}(\mathbf{x}) = t]}{\Pr[\mathcal{T}_{\mathcal{A}}(\mathbf{x}') = t]} \right) \right| \le \epsilon.$$

We sometimes call $\epsilon$ the *leakage*. When $\epsilon$ is small, $\ln(1+\epsilon) \approx \epsilon$, and so the definition is roughly equivalent to requiring that for all transcripts $t$, $\frac{\Pr[\mathcal{T}_{\mathcal{A}}(\mathbf{x})=t]}{\Pr[\mathcal{T}_{\mathcal{A}}(\mathbf{x}')=t]} \in 1 \pm \epsilon$.

# Goal

For image $I$, transformation $T$ from a valid set of transformations given by [[C2PA]] and [[Digital Signature Scheme]] $\Sigma = (KGen, Sign, Ver)$ with verification key $vk$
ZKP $R_{\text{vk}} = \{((I_T, T); (I, \sigma)) : I_T = T(I) \land \text{Ver}(\text{vk}, I, \sigma) = 1\}$
## Parameters
- **Public Data (Anyone can see this):**
  - **$I_T$ (Transformed Image):** The final, edited image you are looking at.
  - **$T$ (Transformation):** The exact list of edits applied (e.g., crop, grayscale).
  - $vk$ (public key) and ${Ver}$ is also public.
- **Private Data (The "Witness" - kept secret by the prover):**
  - **$I$ (Original Image):** The raw, unedited photo straight from the camera.
  - **$\sigma$ (Signature):** The digital signature generated by the camera for that raw photo.
## Equation
For the proof to be accepted,
1. **$I_T = T(I)$**: Applying the public edits ($T$) to the hidden original image ($I$) results exactly in the public final image ($I_T$). 
2. **$\text{Vrfy}(\text{vk}, I, \sigma) = 1$**: The hidden original image ($I$) and its hidden signature ($\sigma$) perfectly pass the public verification test using the camera's public key ($\text{vk}$).

# Notations
## Basic Notation
* **Security Parameter:** ([[Security Parameter]]) Denoted by $\lambda$.
* **Negligible Function:** ([[5-One Way Functions#^59b5e7]]) A function $f: \mathbb{N} \to \mathbb{R}^{\ge 0}$ is negligible in $\lambda$ if for every $k \in \mathbb{N}$, there exists a $\lambda_0 \in \mathbb{N}$ such that for every $\lambda \ge \lambda_0$, $|f(\lambda)| \le 1/\lambda^k$.
* **Random Process:** The output $x$ of a random process $A(\cdot)$ is denoted as $x \leftarrow A(\cdot)$.
* **Conditional Probability:** The probability of event $A$ given event $B$ is $\Pr[A \mid B]$.
* **Sets:** 
	* $[k]$ denotes $\{0, 1, \dots, k - 1\}$ for $k \in \mathbb{Z}^{\ge 0}$.
    * $[a : b]$ denotes $\{a, a + 1, \dots, b - 1, b\}$ for $a, b \in \mathbb{Z}$ with $a < b$.
* **Linear Algebra:**
    * $\odot$ denotes matrix-vector or matrix-matrix multiplication.
    * $\langle \mathbf{u}, \mathbf{v} \rangle$ denotes the inner product of vectors $\mathbf{u}$ and $\mathbf{v}$.
    * $\mathbb{F}$ denotes fields.
    * Scalars are lowercase, vectors are boldface lowercase, and matrices are boldface uppercase.
* **Protocols & Proof Systems:**
    * In an input tuple like $(a, b, c; d, e)$, variables before the semicolon are public, and those after are private.
    * $R$ typically denotes a relation (a set of statement/witness pairs).

## Notation for Polynomials
* **Multilinear Polynomial:** A multivariate polynomial that is linear in each variable (no variable has a degree greater than one).
* **Total Degree:** The maximum sum of the variable degrees across all monomial terms in the polynomial.
* **Polynomial Vectors:** $\mathbf{x}$ denotes vectors representing evaluation points, and $\mathbf{X}$ denotes vectors of indeterminates.
* **Boolean Hypercube:** Denoted as $\mathbb{B}_\mu := \{0, 1\}^\mu$.
